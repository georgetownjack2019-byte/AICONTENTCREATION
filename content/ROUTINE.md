# Daily routine: trend shorts

## Per short
| Step | You | Claude |
|---|---|---|
| 1. Trends | Run the **Virlo** workflow and share the markdown (paste in chat or save to `content/trends/`). Optionally add any trend you saw yourself. | Searches **vidIQ** (TikTok + Instagram outliers), merges it with your Virlo report, and gives you a shortlist of 3–5 trends adapted for Kenji & Yuki. You pick. |
| 2. Plan | Reply "go" or "change X" | Shot plan: hook text, shots, outfits, setting, expressions, timing, credit cost |
| 3. Stills | "good" / "redo shot N" | Generates one image per shot from the official reference sheets, checks them first (~2 credits each) |
| 4. Animate | Approve the cost, then "good" / "redo" | Animates each still into a 5 s clip, checks them (~7.5 credits per clip) |
| 5. Download | Download the clips | Saves copies in the repo |
| 6. Edit | CapCut: clips in order, trending sound, hook text, captions, export 1080×1920 | Gives the hook text, captions, clip order |
| 7. Post | TikTok (sound in-app, **AI label on**) → Instagram 1 h later (clean CapCut file, **AI label on**) | Writes captions, hashtags, pinned comment per platform |
| 8. Track | Next day: send views / watch time / shares | Logs results, says what to make more of |

## Daily timing (2 shorts)
- Morning (~30–40 min): trends → approve plans and stills → download → edit
- 12:30 pm TikTok / 1:30 pm IG: short 1
- 7:30 pm TikTok / 8:30 pm IG: short 2
- Next morning: send numbers

## Starting a session
Open Claude Code on this repo and say, for example, "Make today's 2 trend shorts, here's my Virlo report: …".
Claude reads `characters/BIBLE.md`, `characters/PROMPTS.md`, `content/formats/` and `content/trends/` first.

## Only you can
Post (Instagram always; TikTok recommended in-app for trending sounds) · add in-app sounds ·
approve anything that costs credits · keep account logins private.
